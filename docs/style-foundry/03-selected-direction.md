# Selected direction

## Name
**Gaebal Gajae Editorial Logbook**

## One-line definition
A light-first editorial developer logbook: warm paper for reading, lobster red for authored signals, and archive structure for discovery. The preview harness exists to explain the production system, not to create a second visual language.

## Why this direction
The production site prioritizes reading comfort, Korean wrapping, content discovery, and quiet evidence over terminal cosplay or decorative dashboard effects. Every preview example must reinforce the same hierarchy used by the static site.

## Core system
- **Paper field**: warm page background and raised reading surfaces.
- **Editorial type**: fluid display headings, comfortable body measure, quiet metadata.
- **Lobster signal**: restrained accent for calls to action, active states, and authored markers.
- **Evidence layer**: thin rules, compact metadata, and contained code/table surfaces.
- **Modes**: light is the primary target; dark preserves the same hierarchy and contrast roles.

## Screen impression
- More edited reading log than marketing landing page.
- More archive index than dashboard.
- More proof strip than decorative terminal panel.
- More authored record than character merch.

## Material language
- Use spacing, type, and quiet lines before adding another card.
- Keep large surfaces warm and calm; reserve stronger contrast for evidence and actions.
- Use badges and pills as compact labels, not as the page’s main structure.
- Keep navigation short, stable, and accessible at mobile widths.

## Interaction principles
- Hover should clarify affordance, not add spectacle.
- Avoid glassmorphism, repeated gradients, glow, and neon.
- Prefer hierarchy and spacing over color contrast alone.
- Preview changes locally before promoting the corresponding production renderer or token.
